# LACE map

Generated from the glossary files. Do not edit by hand.

Every chain that stands on its own, with the chains that come off it, then the Flower, the links and the sides. Indented chains belong to the one above.

## Attention

How attention itself works.

- **Attention**: Trigger → Detection → Selection → Focus → Processing → Attention Grip → Notice

## Perception

How anything, inside or outside, gets noticed and starts to mean something.

- **Perception**: Occurrence → Senses → Detection → Attention → Notice → Recognition → Perception → Meaning → Response → Integration
  - **Appreciation** (spur): Attention → Recognition → Value Assignment → Emotional Response → Acknowledgment

## Thought

From thought to reality.

- **Thought**: Thought → Repetition → Belief → Perception → Emotion → Action → Habit → Behaviour → Results → Reinforcement → Reality
  - **Belief Formation** (zoom-in): Information → Exposure → Perception → Evaluation → Acceptance → Reinforcement → Belief → Reflection
    - **Acceptance** (spur): Reality → Recognition → Emotional Response → Processing → Acknowledgment → Adaptation
    - **Faith** (spur): Question or Experience → Exploration → Perception → Belief → Trust → Practice → Reflection
    - **Morality** (spur): Situation → Recognition → Perception → Reasoning and Emotion → Judgment → Choice → Reflection
    - **Values** (spur): Experience → Evaluation → Preference → Principle → Prioritization → Expression → Reflection
      - **Preference** (zoom-in): Exposure → Emotional Response → Like or Dislike → Comparison → Preference → Choice → Reinforcement
  - **Habit** (zoom-in): Trigger → Urge → Behaviour → Aftermath → Reinforcement → Repetition → Habit
    - **Avoidance** (spur): Discomfort → Survival Scan → Urge to Escape → Avoidance → Temporary Relief → Reinforcement
    - **Conditioning** (spur): Trigger → Association → Response → Aftermath → Repetition → Habit
    - **Discipline** (spur): Goal → Competing Chains → Chain Break → Action → Repetition → Habit
    - **Procrastination** (spur): Task → Discomfort → Delay → Temporary Relief → Accumulating Pressure → Action or Further Delay
    - **Reward** (spur): Behaviour → Aftermath → Evaluation → Pleasure or Relief → Learning → Future Motivation
    - **Routine** (spur): Intention → Planning → Sequence → Repetition → Familiarity → Consistency → Maintenance
  - **Identity** (zoom-in): Experience → Perception → Belief → Identification → Expression → Feedback → Integration → Evolution
    - **Confidence** (spur): Challenge → Attempt → Experience → Reinforcement → Competence → Self-Efficacy → Confidence
    - **Self-Concept** (spur): Experience → Self-Observation → Comparison → Perception → Belief → Self-Description → Revision
    - **Self-Esteem** (spur): Experience → Self-Evaluation → Perceived Worth → Emotion → Self-Regard → Reinforcement
    - **Social Comparison** (spur): Attention → Comparison → Evaluation → Emotional Response → Self-Assessment → Adjustment
  - **Imagination** (spur): Trigger → Association → Visualization → Possibility → Exploration → Elaboration → Creation
  - **Problem-Solving** (spur): Problem → Identification → Analysis → Possibilities → Selection → Experimentation → Reflection → Solution
  - **Reasoning** (spur): Question → Information → Assumptions → Analysis → Inference → Conclusion → Reflection
  - **Understanding** (spur): Information → Perception → Linking → Integration → Comprehension → Explanation → Application

## Emotion

Every emotion runs through this.

- **Emotion**: Trigger → Perception → Emotional Response → Emotion → Emotional Expression → Emotion Checkpoint → Resolution
  - **Anger** (spur): Provocation → Perception → Frustration → Body Signals → Impulse → Expression or Regulation → Outcome
  - **Anxiety** (spur): Uncertainty → Survival Scan → Worry → Body Signals → Coping or Avoidance → Reinforcement
  - **Arousal** (zoom-in): Trigger → Detection → Body Signals → Increased Readiness → Response → Regulation
  - **Boredom** (spur): Low Engagement → Dissatisfaction → Desire for Stimulation → Exploration or Withdrawal → Re-engagement
  - **Emotional Regulation** (zoom-in): Emotion → Emotional Awareness → Identification → Acceptance → Strategy → Chain Break → Reflection
  - **Enjoyment** (spur): Experience → Perception → Pleasure → Engagement → Savouring → Satisfaction
  - **Fear** (spur): Survival Scan → Perception → Body Signals → Fear → Emotional Response → Outcome → Learning
  - **Gratitude** (spur): Benefit → Recognition → Attribution → Appreciation → Thankfulness → Expression
  - **Grief** (spur): Loss → Recognition → Emotional Response → Adjustment → Meaning-Making → Integration → Continuing Life
  - **Joy** (spur): Positive Experience → Perception → Pleasure → Expression → Savouring → Memory → Wellbeing
  - **Shame** (spur): Experience → Self-Evaluation → Perceived Inadequacy → Shame → Withdrawal or Repair → Reassessment
  - **Stress** (spur): Demand → Perception → Body Signals → Coping Response → Recovery or Prolonged Stress
  - **Wonder** (spur): Extraordinary Stimulus → Attention → Surprise → Awe → Curiosity → Reflection → Meaning

## Action

From something prompting you to act, to what the action leaves behind.

- **Action**: Trigger → Attention → Motivation → Intention → Planning → Initiation → Action → Monitoring → Completion → Aftermath → Reflection → Reinforcement
  - **Collaboration** (spur): Shared Interest → Alignment → Roles → Communication → Coordination → Contribution → Joint Outcome
  - **Decision** (zoom-in): Situation → Options → Evaluation → Preference → Intention → Commitment → Outcome → Reflection
  - **Full Grip** (spur): Challenge → Skill Engagement → Attention → Attention Grip → Sustained Activity → Satisfaction
  - **Impulse** (spur): Trigger → Urge → Body Signals → Inhibition or Action → Consequence → Learning
  - **Legacy** (spur): Values → Intention → Contribution → Action → Aftermath → Remembrance or Continuation
  - **Motivation** (zoom-in): Need or Desire → Value → Expectation → Drive → Intention → Effort → Reinforcement
  - **Planning** (zoom-in): Objective → Information → Constraints → Options → Prioritization → Sequencing → Schedule → Reflection
  - **Play** (spur): Opportunity → Interest → Spontaneous Engagement → Experimentation → Enjoyment → Learning

## Memory

From something happening to a stored memory that shapes what comes next.

- **Memory**: Occurrence → Attention → Perception → Emotion → Encoding → Consolidation → Memory → Meaning → Integration → Influence → Reinforcement
  - **Learning** (spur): Intake → Attention → Comprehension → Encoding → Practice → Feedback → Memory → Application
    - **Skill** (spur): Exposure → Instruction → Practice → Error → Feedback → Adjustment → Skill Levels
      - **Mastery** (spur): Interest → Learning → Deliberate Practice → Feedback → Refinement → Mastery → Adaptation
  - **Meaning-Making** (zoom-in): Occurrence → Perception → Context → Personal Significance → Narrative → Integration
  - **Nostalgia** (spur): Trigger → Memory → Emotional Reconstruction → Longing or Affection → Reflection
  - **Reflection** (spur): Experience → Recall → Examination → Perception → Insight → Reflection → Learning
  - **Trauma Response** (spur): Overwhelming Experience → Survival Scan → Encoding → Survival Scan → Trigger → Emotional Response → Adaptation

## Desire

From wanting something to it coming true (or not).

- **Desire**: Desire → Wish → Visualization → Emotion → Belief → Intention → Alignment → Action → Persistence → Outcome → Reflection
  - **Ambition** (spur): Aspiration → Visualization → Goal → Commitment → Effort → Persistence → Achievement → Reflection
  - **Commitment** (zoom-in): Choice → Intention → Promise → Prioritization → Effort → Consistency → Accountability
  - **Curiosity** (spur): Novelty → Attention → Known Limit → Interest → Question → Exploration → Discovery → Satisfaction
    - **Exploration** (spur): Curiosity → Interest → Approach → Investigation → Discovery → Learning → Further Curiosity
      - **Adventure** (spur): Desire → Possibility → Risk Evaluation → Decision → Exploration → Experience → Reflection
  - **Fulfillment** (spur): Values → Meaningful Pursuit → Engagement → Accomplishment or Connection → Reflection → Satisfaction
  - **Goal** (spur): Desire → Definition → Intention → Planning → Action → Monitoring → Achievement or Revision
    - **Achievement** (spur): Goal → Commitment → Preparation → Effort → Obstacles → Adaptation → Completion → Recognition
  - **Hope** (spur): Desire → Uncertainty → Perceived Possibility → Positive Anticipation → Motivation → Persistence
  - **Satisfaction** (zoom-in): Expectation → Experience → Comparison → Evaluation → Fulfillment or Dissatisfaction

## Communication

How a thought gets from one person into another's chains, and back.

- **Communication**: Thought → Intention → Encoding → Expression → Transmission → Reception → Decoding → Perception → Emotion → Response → Feedback → Understanding
  - **Persuasion** (spur): Exposure → Attention → Credibility → Interpretation → Persuasion or Social Pressure → Attitude or Behaviour Change

## Connection

How a relationship forms and keeps going. Shared by nature.

- **Connection**: Encounter → Attention → Perception → Interest → Approach → Communication → Recognition → Alignment → Reciprocity → Trust → Vulnerability → Bond → Belonging → Maintenance
  - **Attraction** (spur): Encounter → Perception → Interest → Alignment → Desire for Proximity → Approach → Reciprocity or Rejection
  - **Belonging** (spur): Encounter → Participation → Acceptance → Reciprocity → Identification → Inclusion → Security
  - **Conflict** (spur): Difference → Perception → Disagreement → Emotional Response → Expression → Escalation or Resolution → Outcome
  - **Empathy** (spur): Attention → Recognition → Perspective-Taking → Emotional Understanding → Concern → Response
  - **Forgiveness** (spur): Perceived Wrong → Hurt → Processing → Reappraisal → Decision or Emotional Shift → Charge drops
  - **Friendship** (spur): Encounter → Interaction → Familiarity → Shared Experience → Reciprocity → Trust → Bond → Maintenance
  - **Intimacy** (spur): Interest → Openness → Disclosure → Responsiveness → Safety → Mutual Understanding → Closeness
  - **Love** (spur): Attraction or Affection → Interest → Emotional Closeness → Vulnerability → Bond → Care → Commitment or Ongoing Bond
  - **Reconciliation** (spur): Rupture → Acknowledgment → Dialogue → Accountability → Repair → Reflection → Renewed Relationship or Separation
  - **Trust** (zoom-in): Interaction → Expectation → Vulnerability → Observed Reliability → Confidence → Repetition → Trust

## Need

From a need running low to it being met.

- **Need**: Deficit → Body Signals → Discomfort → Motivation → Seeking → Fulfillment → Satisfaction
  - **Energy Regulation** (spur): Intake and Expenditure → Body Signals → Physiological Adjustment → Behavioural Response → Feedback
  - **Fatigue** (spur): Exertion or Insufficient Recovery → Fade → Attention → Behavioural Adjustment → Rest → Recovery
  - **Hunger** (spur): Energy Regulation → Body Signals → Attention → Food Seeking → Eating → Satiety → Feedback
  - **Pain** (spur): Body Signals → Nervous System Processing → Perception → Emotional Response → Protective Response → Modulation
  - **Recovery** (spur): Strain or Injury → Protective Response → Repair Processes → Rest and Adaptation → Functional Restoration
  - **Sleep** (spur): Wakefulness → Sleep Pressure and Circadian Timing → Sleepiness → Sleep Initiation → Sleep Cycles → Awakening
  - **Thirst** (spur): Body Signals → Attention → Water Seeking → Drinking → Quenched → Feedback

## Creation

How Creation happens, step by step.

- **Creation**: Inspiration → Visualization → Intention → Design → Action → Refinement → Finished Work
  - **Design** (spur): Need → Research → Definition → Ideation → Prototyping → Testing → Iteration → Solution
  - **Innovation** (spur): Opportunity → Insight → Idea → Experiment → Validation → Implementation → Adoption → Evolution
  - **Invention** (spur): Need or Problem → Insight → Concept → Experimentation → Prototype → Refinement → Novel Solution

## Change

The steps of Chain Change.

- **Change**: Notice → Dissatisfaction or Opportunity → Intention → Preparation → Experimentation → Repetition → Integration
  - **Resilience** (spur): Impact → Response → Coping → Adaptation → Recovery → Learning → Growth
  - **Transformation** (spur): Impact → Questioning → Exploration → Reassessment → Change → Integration → New Orientation
