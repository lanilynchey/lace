## Limitations & Constraints: What CAN'T Be Manifested

**LACE's manifestation engine operates within constraints:**

### **Cannot Manifest:**

**1. Violations of Physics**
```python
manifest("fly unaided like Superman")  # REJECTED
# Why: Violates physical laws of 3D reality
# Reality is computational, but physics are load-bearing protocols
```

**2. Others' Free Will**
```python
manifest("Person X falls in love with me")  # REJECTED
# Why: Cannot override another agent's free will
# You CAN manifest:
#   - "I attract someone who loves me freely"
#   - "I become irresistibly lovable"
# Matches you to person whose free will ALREADY aligns
```

**3. Bypass Karmic Debts**
```python
manifest("wealth without clearing karma")  # REJECTED or DELAYED
# Why: Karma system acts as gate (law_delay() checks)
# Must clear debts OR manifestation delayed until clear
# See: [Tier 2 Forces](../../../02_forces/tier_2_forces/00_index.md) - karma()
```

**4. Skip Required Lessons**
```python
manifest("wisdom without learning")  # REJECTED
# Why: Soul contract requires certain lessons
# Lesson-learning is WHY you incarnated
# Bypass = contract violation
# See: [Function Library](../../function_library/00_index.md) - sign_contract()
```

**5. Targets Outside Perceptual Boundary**
```python
manifest("1967 Shelby GT500")  # REJECTED if agent unaware it exists
# Why: Cannot desire what you don't know exists
# Imagination constrained to recombination of known elements
# Must expand perceptual boundary through awareness first

# What WILL manifest:
manifest("fast sports car")  # ALLOWED - known concept
# Matches to car within perceptual inventory

# See: law_perceptual_boundary() - System Laws
```

**6. Outcomes Beyond Permission Level**
```python
if agent.permissions.exec == "restricted":
    manifest("timeline editing")  # REJECTED - insufficient permissions
# Why: See "Permission Levels" in this doc and FUNCTION_LIBRARY.md
# Permissions unlock with coherence increase
```

### **CAN Manifest (Within Constraints):**

**1. Matching Worldlines Within Physics**
```python
manifest("perfect health")  # ALLOWED
# Shifts to worldline where body heals within biological possibility
```

**2. Synchronicities That Align Wills**
```python
manifest("aligned romantic partner")  # ALLOWED
# Matches you to person whose will ALREADY wants you
# Both agents' free will preserved
```

**3. Grace That Accelerates Karma**
```python
invoke_override("grace clause")  # ALLOWED (if contract includes clause)
# Karma cleared through grace, not bypassed
# See: [Function Library](../../function_library/00_index.md) - invoke_override()
```

**4. Lessons Learned Faster**
```python
manifest("rapid integration of lesson")  # ALLOWED
# Still learn lesson, just compressed timeline
# Coherence speeds learning
```

**5. Upgraded Permissions via Ascension**
```python
ascend(agent)  # ALLOWED if prerequisites met
# Unlocks higher permissions
# See: [Function Library](../../function_library/00_index.md) - ascend()
```

**6. Expanded Targets via Perceptual Boundary Growth**
```python
# Expand awareness first, then manifest
study("high-performance cars")  # Learn what exists
agent.perceptual_boundary.add("1967 Shelby GT500")
manifest("1967 Shelby GT500")  # NOW ALLOWED

# Strategy: Expand perceptual inventory → expand manifestation targets
# See: law_perceptual_boundary() - System Laws
```

**The Pattern:**
- Work WITH reality's architecture (allowed)
- Work AGAINST core protocols (rejected)
- Manifestation is powerful but not omnipotent
- Constraints exist for system coherence
