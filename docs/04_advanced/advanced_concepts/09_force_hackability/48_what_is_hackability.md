# 8. Force Hackability

## **What Is Force Hackability?**

**Hackability** refers to how easily agents can consciously manipulate or influence a force. Some forces are highly hackable (agents can directly control them), while others are nearly immutable (operate beyond agent control).

**Hackability Scale:**
- **Very High** - Direct conscious control, immediate response
- **High** - Trainable skill, accessible with practice
- **Medium** - Possible but difficult, requires sustained effort or special states
- **Low** - Indirect influence only, very limited agent control
- **Very Low** - Nearly immutable, operates beyond agent reach
