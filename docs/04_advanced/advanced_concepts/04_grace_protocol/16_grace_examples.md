# Examples of Grace

**1. Spontaneous Remission (Cancer disappears)**
```python
grace_event = GraceProtocol(
    type="healing",
    trigger="soul_readiness + collective_prayer",
    effect="cancer_dissolved",
    karma_bypassed="death_timeline"
)
```

**2. Impossible Rescue (Shouldn't have survived)**
```python
grace_event = GraceProtocol(
    type="protection",
    trigger="mission_incomplete",
    effect="death_prevented",
    karma_bypassed="fatal_consequence"
)
```

**3. Sudden Abundance (Money appears from nowhere)**
```python
grace_event = GraceProtocol(
    type="provision",
    trigger="surrender + alignment",
    effect="resources_manifested",
    karma_bypassed="scarcity_lesson"
)
```
