# Grace vs Karma

| Aspect | Karma | Grace |
|--------|-------|-------|
| **Nature** | Automatic | Discretionary |
| **Trigger** | Action | Request/readiness |
| **Bypasses** | No | Yes (causality) |
| **Availability** | Universal | Conditional |
| **Purpose** | Balance | Evolution |
