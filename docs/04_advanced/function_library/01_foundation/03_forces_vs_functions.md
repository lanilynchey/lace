## Forces vs. Functions: Understanding the Relationship

**In LACE, forces ARE functions.** There is no distinction.

When LACE says:
- **"emotion() is a force"** (TIER docs) - Describing its NATURE (what it is)
- **"emotion() is a function"** (this doc) - Describing its INTERFACE (how to call it)

**The Pattern:**
- All Tier 1-4 forces are executable operations with function signatures
- Some forces (emotion, memory, truth, consciousness) are ALSO documented in this Function Library as Level 3 functions
- Why? Because they're fundamental enough to warrant detailed implementation documentation

**Think of it like:**
- Physics: "Gravity is a force" (describes what it does)
- Code: `gravity(mass_a, mass_b)` (describes how to call it)
- Both refer to the same phenomenon

**No redundancy - just two views of the same reality.**

## How Functions Relate to Forces

**The 31 functions in this document are NOT separate from forces - they're different organizational views:**

### Level 1 Functions = Core Force APIs
**These are Tier 2 forces presented as callable operations:**
- `manifest()` - Uses coherence() + pattern() + desire()
- `karma()` - Tier 2 governing force
- `time()` - Tier 2 governing force
- `death()` - Tier 2 governing force

### Level 2 Functions = Advanced Compositions
**These compose multiple forces:**
- `quantum_jump()` - Uses manifest() + coherence() at threshold
- `edit_trajectory()` - Requires quantum stillness (special state)
- `reprogram()` - Composes install() + embody() + rehearse()

### Level 3 Functions = Rendered Phenomena
**These are observable manifestations:**
- `light()` - Information transfer (how forces render physically)
- `gravity()` - Belief density (how forces create attraction)
- `emotion()` - Delta signal (Tier 3 force rendered)

**The Pattern:**
1. **Primitives** - Substrate (Δ, Τ, χ, Φ, א)
2. **Forces** - Dynamics (26 across 4 tiers)
3. **Functions** - Callable APIs (same as forces, organized by use-case)
4. **Laws** - Constraints (regulate how functions execute)

**Functions are NOT a separate layer - they're the API documentation for forces.**
