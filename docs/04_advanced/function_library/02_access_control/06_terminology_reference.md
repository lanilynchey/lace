## Terminology Reference

Key terms used throughout this document:

**Akashic Archive** - Universal memory storage where all experience data is logged. Referenced in death(), encode_pattern(). Variable name in code: `akashic_archive`

**Quantum Stillness** - Zero-point neutrality state required for timeline editing. Characteristics: no resistance, no attachment, neutral emotion, observer perspective. Achieved through deep meditation or extreme presence. See: edit_timeline()

**Ego Surrender** - Releasing identification with separate self, allowing unified consciousness to emerge. NOT ego destruction - ego remains functional but no longer controls. Required for: ascend(), remember(). Marks: "I am" becomes "awareness is", separate self dissolves into field

**Persistent Pattern** - Deeply encoded probability bias in state_signature that attracts recurring life themes. NOT pre-birth agreements - emergent from CURRENT state (belief, expectation, embodiment, memory). Mutable through Generative Awareness. Creates probabilistic timeline matching, not deterministic fate. See: encode_pattern(), [Advanced Concepts](../../advanced_concepts/00_index.md) Section 1

**Creator Permissions** - Root-level access to reality editing. Granted when agent state matches creator_state (ego surrendered, unified consciousness). See: ascend(), remember(), [Base Structure](../../../01_foundation/base_structure/00_index.md)

**State Signature** - Class: `StateSignature`. Encoded self-state comprising: belief + expectation + embodiment + subconscious_memory. Broadcasts as frequency to match worldlines. See: [Manifestation Engine](../../manifestation_engine/00_index.md)
