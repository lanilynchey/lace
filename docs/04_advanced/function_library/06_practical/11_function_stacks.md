These show how functions compose in real-world usage patterns.

  ↓
reprogram() [Level 2 function] - Dissolve limiting beliefs, install expansive
  ↓
embody(target_state) - Rehearse new pattern somatically
  ↓

  ↓

  ↓

### **Stack 2: Healing & Integration**
```
Trauma Detected
  ↓
pain() [Tier 3 force] - Alert signal fires (misalignment detected)
  ↓
heal(wound) [Level 1 function] - Apply sustained attention
  ↓
IF presence >= threshold:
    transmute(wound) - Energy transforms
    ↓
    forgiveness() [Tier 3 force] - Release charge, dissolve loop
    ↓
    Integration Complete
ELSE:
    suppress(wound) - Wound compressed into body
    ↓
    loop_detected() [Level 2 function] - Pattern repeats
    ↓
    Return to pain() until ready
```

**Usage Notes:**
- heal() requires sustained presence WITHOUT resistance
- Suppression creates background loops (unresolved trauma)
- forgiveness() is THE loop-terminating function
