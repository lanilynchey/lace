# Key Mechanics

## **Manifestation**

Reality experience = broadcast frequency (state_signature) driving how the single shared state mutates.

- **Soma as Compiler**: The body encodes internal state as transmittable frequency
- **State Signature**: Computed from belief + expectation + embodiment + subconscious_memory
- **State Mutation**: Probabilistic (Gaussian distribution) based on coherence level
- **Not Instant**: Requires coherent state + aligned action + time

**How It Works:**
1. Agent's internal state (beliefs, expectations, embodied patterns, subconscious memory) → encoded by body (soma)
2. Body broadcasts this as a frequency signature into the field
3. The field validates the mutation that frequency implies against its own constraints
4. The outcome that renders lands probabilistically around the intended target (probabilistic, not deterministic)
5. Agent experiences the state that actually rendered
6. Higher coherence = narrower spread around target (more "precise" manifestation)
7. Lower coherence = wider scatter (unpredictable experience)
