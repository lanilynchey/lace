# Key Mechanics

## **Manifestation**

Reality experience = matching broadcast frequency (state_signature) to timeline probability fields.

- **Soma as Compiler**: The body encodes internal state as transmittable frequency
- **State Signature**: Computed from belief + expectation + embodiment + subconscious_memory
- **Timeline Matching**: Probabilistic (Gaussian distribution) based on coherence level
- **Not Instant**: Requires coherent state + aligned action + time

**How It Works:**
1. Agent's internal state (beliefs, expectations, embodied patterns, subconscious memory) → encoded by body (soma)
2. Body broadcasts this as a frequency signature into the field
3. Field contains multiple possible timelines, each with its own frequency
4. State signature matches to timeline with similar frequency (probabilistic, not deterministic)
5. Agent experiences events from the matched timeline
6. Higher coherence = narrower matching (more "precise" manifestation)
7. Lower coherence = wider scatter (unpredictable experience)
