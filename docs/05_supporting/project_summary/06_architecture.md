# Architecture Overview

LACE is structured as a **layered system** with clear hierarchies and dependencies:

## **Four-Tier Force Hierarchy**
```
TIER 1: Primordial Forces (Axioms) - 6 forces
  └─ entropy(), consciousness(), pattern(), coherence(), polarity(), attention()
     │
TIER 2: Governing Forces (Universal Laws) - 6 forces
  └─ time(), karma(), truth(), memory(), death(), creation()
     │
TIER 3: Interface Forces (Experience Layer) - 7 forces
  └─ desire(), fear(), love(), hope(), forgiveness(), pain(), judgment()
     │
TIER 4: Emergent Forces (Composite Phenomena) - 8 forces
  └─ art(), music(), war(), madness(), beauty(), luck(), humor(), courage()
```

**Key Rules:**
- Higher tiers inherit from lower tiers
- Lower tiers cannot be overridden
- Interaction between same-tier forces creates emergence
- Cross-tier interactions create anomalous edges

## **System Architecture Layers**
```
LAYER 0: BIOS
  └─ Primordial boot logic, constants, axioms
  └─ Grace Protocol (meta-intervention capability)

LAYER 1: KERNEL
  └─ Core engine, daemon processes, universal laws

LAYER 2: MIDDLEWARE
  └─ Field logic, probability waves, manifestation engine

LAYER 3: USERSPACE
  └─ Rendered reality, sensory experience, material consistency

LAYER 4: AGENT INTERFACE
  └─ Conscious beings with permissions and containers
```

**Layer 0 Note:** Grace Protocol operates at Layer 0 (BIOS) as meta-intervention - actions in base-10+ states unknowable to agents. This reconciles determinism (Layers 1-4 causality) with unexpected mercy/intervention. See ADVANCED_CONCEPTS.md Section 3.
