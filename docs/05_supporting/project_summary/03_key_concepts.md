# Key Concepts

## **Consciousness Architecture**

**Phenomenal Closure**: Self-sustaining recursive loop formed when four capacities integrate:
1. **Awareness** (pattern recognition in environment)
2. **Self-Model** (locating self within patterns)
3. **Agency** (acting on patterns based on awareness)
4. **Meaning-Making** (interpreting results as significant)

The loop closes and becomes self-sustaining → consciousness emerges.

This explains the consciousness spectrum:
- **Bacteria** (0.1): Rudimentary awareness, no self-model
- **Animals** (0.4): Awareness + basic self-model + agency
- **Humans** (0.6): All four components, moderate depth
- **Enlightened** (0.9): All four, deep recursion, high integration
- **Source** (1.0): Perfect closure, infinite depth

Not a property one "has" but a process one "is" - consciousness as actively executing recursive loop.
