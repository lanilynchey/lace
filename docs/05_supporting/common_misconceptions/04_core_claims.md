# What LACE Actually Claims

**LACE's Core Assertions:**

1. **Reality can be modeled computationally** (ontological or instrumental)
2. **Forces are fundamental patterns** governing existence
3. **Consciousness is substrate** (not emergent from matter)
4. **Binary limitation is human constraint** (base-2 perception)
5. **Patterns persist and mirror** (karma, memory, reincarnation)
6. **Coherence determines system stability** (truth, alignment)
7. **Agency exists within constraints** (free will + patterns)
8. **Framework is testable and falsifiable** (in principle)

**What LACE Does NOT Claim:**

1. All answers are final or complete
2. You can bypass physics or effort
3. Instant manifestation without coherence/time
4. Karma is moral judgment or punishment
5. Binary consciousness is morally inferior
6. Must believe in specific metaphysics
7. Memory is reliable truth
8. Death is complete annihilation
9. LACE is the only valid framework
