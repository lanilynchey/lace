**❌ Wrong:**
- Universe judges you as good/bad
- Karma is cosmic revenge
- Bad things happen because you "deserve" it

**✅ Correct:**
- karma() is MIRRORING, not punishment
- Pattern echo mechanism, not moral judgment

**Reality:**
If you harm others, karma() returns that pattern to you - not because you're "bad," but because the system mirrors all patterns. Like echo in canyon - sound doesn't judge, it just reflects.
