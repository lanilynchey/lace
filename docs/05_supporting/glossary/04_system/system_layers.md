# System Layer Terms

## **BIOS** (Layer 0)
**Definition:** Primordial boot logic - initializes universe before it "runs"

**Functions:** Sets constants, defines dimensions, launches base laws, seeds consciousness

**Access:** Creator only

---

## **Kernel** (Layer 1)
**Definition:** Core execution engine

**Functions:** Manages time, memory, karma, agent lifecycle, daemon processes

**Access:** Partially accessible to mystics/masters (influence, not override)

---

## **Middleware** (Layer 2)
**Definition:** Field logic layer

**Functions:** Manifestation matching, synchronicities, probability waves, belief modulation

**Access:** Accessible through meditation, ritual, altered states

---

## **Userspace** (Layer 3)
**Definition:** Rendered reality - the "output" layer

**Functions:** Sensory input/output, material consistency, time perception

**Access:** Default human experience level

---

## **Agent Interface** (Layer 4)
**Definition:** Conscious entities with permissions

**Functions:** Containerized processes interacting with system

**Access:** Varies by consciousness level and coherence

---
