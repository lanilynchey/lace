# Manifestation Terms

## **Timeline / Worldline**
**Definition:** Possible experiential path through reality

**Properties:**
- Has frequency signature
- Contains potential events
- Probability of matching = alignment with agent frequency
- You don't create timelines - you match to existing ones

---

## **Coherence**
**Definition:** Internal harmony - alignment of signal components

**Formula:** `coherence = 1 / (1 + variance(components))`

**Properties:**
- High coherence = stable, strong manifestation power
- Low coherence = scattered, weak signal
- Measured as inverse of variance

**Threshold:** Below ~0.4 coherence, manifestation fails

---

## **Entanglement**
**Definition:** Field connection between agents where state changes affect each other

**Properties:**
- Forms when frequencies resonate
- Persists beyond physical proximity
- Decays over time if not maintained
- Example: Love creates entanglement
