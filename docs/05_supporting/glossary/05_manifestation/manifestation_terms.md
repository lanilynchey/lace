# Manifestation Terms

## **StateTrajectory**
**Definition:** The single actual path an agent's state has taken through reality - not one of many possible paths (see [`working/timeline_model_revision.md`](../../../../working/timeline_model_revision.md) for the full revision from the old "Timeline/Worldline" model)

**Properties:**
- Has frequency signature
- Contains actual events (what happened, not what might have)
- Projection confidence = likelihood the currently-computing next state resolves as projected
- You don't select a trajectory - your mutations directly compose the one you have

---

## **Coherence**
**Definition:** Internal harmony - alignment of signal components

**Formula:** `coherence = 1 / (1 + variance(components))`

**Properties:**
- High coherence = stable, strong manifestation power
- Low coherence = scattered, weak signal
- Measured as inverse of variance

**Threshold:** Below ~0.4 coherence, manifestation fails

---

## **Entanglement**
**Definition:** Field connection between agents where state changes affect each other

**Properties:**
- Forms when frequencies resonate
- Persists beyond physical proximity
- Decays over time if not maintained
- Example: Love creates entanglement
