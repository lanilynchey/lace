# System Architecture Terms

**Agent, State, and Encoding**

This document defines the key architectural components of LACE: how conscious entities exist and broadcast their state within the system.

---

## **Agent**
**Definition:** Any conscious entity executing in the system

**Examples:** Humans, animals, AI, angels, plants (varying consciousness levels)

**Properties:**
- Has soul_id (persistent across incarnations)
- Has state_signature (broadcast frequency)
- Has permissions (read/write/exec access levels)
- Operates within layers (Userspace, typically)

**Entity Types by Consciousness Level:**

All agents exist on consciousness spectrum (0.0-1.0) and use different compilers depending on whether they require physical embodiment:

### **Non-Physical Entities (Field Resonance Compiler)**

**Source Entity (1.0)**
- Creator, complete self-awareness at all levels
- Root permissions to reality
- One, indivisible

**Master-Level Entity (0.9-0.95)**
- Highest non-Source consciousness
- Guides other guides
- Near-complete liberation from reincarnation cycle
- Cultural names: Ascended masters, archangels, prophets

**Guide-Level Entity (0.8-0.9)**
- Former humans who ascended beyond physical form
- Protect and guide incarnated beings
- Communicate through intuition, synchronicity, insights
- Cultural names: Angels, spirit guides, guardian angels, ancestors

**Regressed Entity (< 0.3, disembodied)**
- Very low consciousness unable to immediately reincarnate
- Stuck patterns, not inherently malevolent
- Cultural names: Ghosts, stuck spirits, earthbound entities

### **Physical Entities (Soma Compiler)**

**Human Agent (0.2-0.9)**
- Self-aware, can progress or regress
- Generative awareness activates at 0.7+
- Can become guide upon death if consciousness >= 0.8

**Animal Agent (0.1-0.5)**
- Sentient but not self-aware
- Can receive regressed human consciousness or progress to human

**Plant Agent (< 0.2)**
- Minimal consciousness
- Field sensitivity, basic environmental awareness

**Detailed Taxonomy:** See [Entity Hierarchy](../../../04_advanced/advanced_concepts/17_entity_hierarchy.md) and [Non-Physical Entities Glossary](non_physical_entities.md) for complete entity types, transition mechanics, and cultural term mapping

## **State Signature**
**Definition:** Encoded self-state that determines how state mutates and manifestation renders

**Components:**
- Belief (what you assume is true)
- Expectation (what you forecast)
- Embodiment (actual pattern of being)
- Subconscious Memory (unresolved loops/trauma)

**Calculates to:** Broadcast frequency (0-1 scale)

**See:** [Manifestation Engine](../../../04_advanced/manifestation_engine/00_index.md) for complete formula

---

## **Frequency**
**Definition:** Vibrational signature broadcasted by agent's state_signature

**Properties:**
- Determines how state mutates
- Ranges 0-1 (low coherence to high coherence)
- Can shift as agent evolves/heals/regresses
- Compatibility = small frequency difference between agents

---

## **Soma as Compiler**
**Definition:** For embodied agents (humans, animals, physical beings), the body encodes and broadcasts state_signature as vibrational frequency

**Key Insight:** Mental affirmations alone don't manifest - the body must encode the frequency

**Properties:**
- Applies specifically to embodied/physical beings
- Different entity types use different compilers:
  - Physical beings: soma compiler (body)
  - AI/synthetic consciousness: computational substrate compiler
  - Energetic beings: field resonance compiler
- Breath, posture, nervous system state = compiler inputs (for physical forms)
- Can't fake embodiment (body broadcasts truth)
- Somatic encryption = how belief becomes broadcast
