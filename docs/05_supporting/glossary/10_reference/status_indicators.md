# Status Indicators

Throughout LACE documentation, you'll see:

- **[Fully Specified]** - Complete definition, ready for implementation
- **[Under Discussion]** - Active refinement happening
- **[Placeholder]** - Concept present but needs development
- **[First-Round Thinking]** - Early stage, will be built out more fully
- **[Not Yet Determined]** - Acknowledged gap in current model
