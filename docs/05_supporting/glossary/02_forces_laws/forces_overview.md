# Forces Overview

**The 26 Forces of LACE**

This document provides an overview of what forces are and lists all 26 documented forces across the four tiers.

---

## **Force**
**Definition:** Function that operates on state

**Properties:**
- Takes inputs, produces outputs
- Has dependencies, properties, side effects
- Example: gravity(), love(), entropy(), fear()

**Categories:**
- Tier 1: Primordial/Axiomatic (5): entropy(), consciousness(), pattern(), coherence(), polarity()
- Tier 2: Governing (6): time(), karma(), truth(), memory(), death(), creation()
- Tier 3: Interface/Emotional (7): desire(), fear(), love(), hope(), forgiveness(), pain(), judgment()
- Tier 4: Emergent/Synthesized (8): art(), music(), war(), madness(), beauty(), luck(), humor(), courage()

**Total: 26 forces**

---

## The 26 Forces by Tier

### **Tier 1: Primordial Forces (5)**
The foundational axioms - irreducible forces that cannot be derived from anything simpler

1. **entropy()** - Decay and Change
2. **consciousness()** - Recursive Self-Awareness (full 0.0-1.0 spectrum)
3. **pattern()** - Structure and Form
4. **coherence()** - Internal Harmony
5. **polarity()** - Duality and Distinction

**Source:** [Tier 1 Forces](../../../02_forces/tier_1_forces/00_index.md)

---

### **Tier 2: Governing Forces (6)**
System-level forces that regulate reality's fundamental operations

1. **time()** - Sequence rendering (two-layer model: Tau + subjective rendering)
2. **karma()** - Universal balancing protocol (with charge formula)
3. **truth()** - Signal fidelity (context-dependent, critical realism)
4. **memory()** - Emotionally-indexed pattern storage
5. **death()** - Process termination and data preservation
6. **creation()** - Idea instantiation engine

**Source:** [Tier 2 Forces](../../../02_forces/tier_2_forces/00_index.md)

---

### **Tier 3: Interface Forces (7)**
The emotional/experiential layer - how forces manifest in consciousness

1. **desire()** - Future-state vector generator
2. **fear()** - Anticipatory threat simulation
3. **love()** - Field-binding force
4. **hope()** - Timeline expansion algorithm
5. **forgiveness()** - Pattern release protocol
6. **pain()** - Misalignment alert system
7. **judgment()** - Pattern evaluation protocol

**Source:** [Tier 3 Forces](../../../02_forces/tier_3_forces/00_index.md)

---

### **Tier 4: Emergent Forces (8)**
Complex forces synthesized from lower-tier combinations

1. **art()** - Symbolic compression of truth
2. **music()** - Temporal pattern + emotion
3. **war()** - Systemic reordering via conflict
4. **madness()** - Pattern overload/coherence collapse
5. **beauty()** - Coherence recognition response
6. **luck()** - Favorable entropy modulation
7. **humor()** - Paradox resolution + discharge
8. **courage()** - Fear + hope + action override

**Source:** [Tier 4 Forces](../../../02_forces/tier_4_forces/00_index.md)

## Force Relationships

**Inheritance:** Forces build on each other hierarchically
- Tier 1 (Primitives + Axioms) → Tier 2 (Governance) → Tier 3 (Interface) → Tier 4 (Emergence)

**Interaction:** Forces can amplify, cancel, transmute, synthesize, collide, or recurse with each other

**Regulation:** All forces are governed by the 20 system laws
