# [derived] vs [emergent] - Terminology Clarification

**Understanding LACE's Status Tags**

This document clarifies the distinction between [derived] and [emergent] terms in LACE documentation.

---

## What does [derived] mean?

When a force or concept is marked **[derived]**, it means:
- **Not a standalone force** in the 26-force system
- **Derived from** or **composed of** existing documented forces
- **Useful shorthand** for recurring patterns or measurements
- **May be documented** in GLOSSARY but not in force tier files

---

## Examples of [derived] terms

- **emotion()** - Category name for Tier 3 forces (not a separate force)
- **belief()** - Process stage in manifestation (not a force)
- **field_state()** - Measurement of agent configuration (not a force)
- **paradox()** - Pattern type (not a force)
- **language()** - Communication system (not a force)
- **will()** - Choice capacity (not a force, but component of courage/forgiveness)
- **chaos()** - Accelerated entropy phenomenon (not a separate force)
- **simulation()** - Cognitive modeling capacity (not a force, but mechanism used by forces)

---

## What does [emergent] mean?

When something is marked **[emergent]**, it means:
- **Arises from interaction** of simpler forces
- **May be Tier 4 force** (if fully documented) or compound state
- **Real phenomenon** but requires synthesis of multiple forces

---

## Examples of [emergent] phenomena

- **Tier 4 forces** - art(), music(), war(), madness(), beauty(), luck(), humor(), courage()
- **Compound states** - anxious attachment (love + fear), addiction (desire loop)
- **Complex patterns** - synchronicity, flow state, spiritual emergence

---

## Key Distinction

```python
# [derived] = shorthand for existing concepts
emotion() → refers to Tier 3 forces collectively
will() → component used in multiple forces

# [emergent] = new phenomenon from force interaction
courage() → fear + hope + will + action (Tier 4 force)
addiction() → desire + desire + repetition (compound state)
```

---

## Why This Matters

- **[derived]** terms don't need full force documentation (glossary is sufficient)
- **[emergent]** forces may need full documentation if complex enough (Tier 4)
- Both are real and useful, just different ontological status

---

## In LACE's 26-Force System

- **26 documented forces** (Tiers 1-4)
- **Multiple [derived] terms** (shortcuts, measurements, categories)
- **Infinite [emergent] patterns** (force combinations create endless phenomena)
