# will()

**[derived capacity]**

---

## Definition

Intentional choice capacity; the ability to collapse possibility space via conscious decision and direct action toward chosen outcome despite resistance.

---

## Composition

```python
will() = consciousness() + א(Aleph/Divine Intent) + choice_collapse + persistence

# Core function:
def will(agent, options):
    """Collapse probability field via intentional choice"""
    possibilities = expand(options)  # See all options
    evaluation = judge(possibilities)  # Assess each
    choice = select(preferred_option)  # Conscious decision
    commitment = maintain(choice) despite resistance
    return action_toward_chosen_outcome
```

---

## Key Properties

- **Requires consciousness** - Will is conscious choice, not automatic reaction
- **Collapses probability** - Selecting one timeline from many possible
- **Intentional** - Deliberate, not impulsive or reactive
- **Persistent** - Will maintains direction despite obstacles
- **Free (within constraints)** - Agency exists, but patterns bias

- courage() synthesis (will required to act despite fear)

## Will vs. Related Concepts

```python
# Distinctions:
will() ≠ desire()      # Will = choice, Desire = pull
will() ≠ force()       # Will is internal, Force is external
will() ≠ hope()        # Will = commitment, Hope = possibility
will() ≠ discipline()  # Discipline = habit, Will = choice-in-moment

# Will requires:
consciousness + awareness_of_options + capacity_to_choose + commitment_to_act

# Will fails when:
- Consciousness too low (unconscious, automatic)
- Options not perceived (ignorance, blindness)
- Overwhelmed (choice paralysis, trauma)
- Patterns too strong (addiction, compulsion)
```
