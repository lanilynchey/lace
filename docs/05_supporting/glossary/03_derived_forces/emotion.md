# emotion()

**[derived force category]**

---

## Definition

Aggregate category name for Tier 3 interface forces; the felt-sense layer of consciousness rendering force activation as subjective experience.

**NOT a separate force** - emotion is the CATEGORY encompassing all Tier 3 forces.

---

## Composition

```python
tier_3_emotional_forces = [
    desire(), fear(), love(), hope(),
    forgiveness(), pain(), judgment()
]

# "emotion()" refers to activation of any/all Tier 3 forces
# Emotional charge = intensity of Tier 3 force activation
```

---

## Key Properties

- **Categorical term**, not individual force
- emotion() = "the experience of Tier 3 forces activating"
- Different from mood (persistent background state)
- Different from feeling (broader term including physical sensations)

---

## Examples

```python
# When someone says "I'm emotional":
emotional_state = {
    fear(): high,
    pain(): moderate,
    hope(): low,
    # Aggregate = "feeling emotional"
}

# emotion() as measurement:
emotional_charge = sum(intensity(force) for force in tier_3_forces)
```

---

## Why referenced as [derived]

- Not a force itself, but derived FROM Tier 3 force activations
- Emergent property of the interface layer
- Used in formulas as shorthand for "Tier 3 activation level"
