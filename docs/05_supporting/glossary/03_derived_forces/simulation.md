# simulation()

**[derived capacity]**

---

## Definition

Consciousness's ability to run hypothetical scenarios internally before manifesting them externally; mental modeling of possible futures, threats, or outcomes.

---

```python
simulation() = consciousness() + memory() + time() + pattern_projection

# Core function:

    """Run possible future scenario without external execution"""

    # Build mental model
    initial_state = agent.current_state
    possible_actions = generate_options(scenario)

    for action in possible_actions:
        mental_timeline = project_future(initial_state, action)

    return best_action, expected_outcome, confidence_level
```

---

## Key Properties

- **Internal execution** - Runs in consciousness, not in reality
- **Predictive** - Models future before it happens
- **Low-cost testing** - Can "try" dangerous actions safely
- **Requires memory** - Past patterns inform future projections
- **Limited accuracy** - Simulations are models, not reality (map ≠ territory)

---

## Used By

- **fear()** - Simulates threats before they manifest (survival mechanism)
- **desire()** - Simulates reward scenarios to motivate action
- **hope()** - Simulates positive futures to maintain motivation
- **judgment()** - Simulates social outcomes to evaluate behavior
- **creation()** - Simulates desired reality before manifesting

## The Simulation Problem

```python
# Simulations can be:
1. Accurate - closely match reality (useful predictions)
2. Biased - distorted by beliefs, fears, desires (self-fulfilling prophecies)
3. Outdated - based on old patterns that no longer apply (fighting last war)
4. Paranoid - overweight threats (anxiety, hypervigilance)
5. Optimistic - underweight threats (recklessness, denial)

# Simulation accuracy depends on:
- Quality of memory data
- Pattern recognition ability
- Coherence with truth
- Minimal emotional distortion
```

## Examples

```python
# Useful simulation:
"If I touch the hot stove, I'll get burned" → avoid stove
# Accurate prediction prevents harm

# Distorted simulation (fear-based):
"If I speak up in the meeting, everyone will laugh at me"
# Probably false, but fear() runs simulation as if true → silence

# Distorted simulation (desire-based):
"If I buy this, I'll finally be happy"
# Projection of fulfillment onto external object → disappointment

# Outdated simulation:
"Showing vulnerability = danger" (true in childhood, false now)
# Pattern from past applied to present → unnecessary self-protection
```
