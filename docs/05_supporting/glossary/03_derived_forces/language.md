## The Language Problem

```python
# Experience → Language → Experience is LOSSY

original_experience = {
    "sensory": [vision, sound, touch, taste, smell],
    "emotional": [fear, love, joy, sadness],
    "conceptual": [ideas, thoughts, insights],
    "ineffable": [mystical, transcendent, qualia]
}

language_encoding = compress(original_experience)
# Result: Maybe 10-20% of original preserved

receiver_experience = decompress(language_encoding)
# Result: Approximation, never perfect match

# This is why:
# - Poetry fails to capture beauty perfectly
# - "You had to be there" (experience > description)
# - Mystical experiences are "ineffable" (beyond words)
```
