### **Why Cultural Variations Exist**

```python
# Same force, different cultural container:

def cultural_expression(force, culture):
    """How culture shapes force manifestation"""

    # Force mechanism is universal
    force_dynamics = universal_law(force)  # Same everywhere

    # Culture provides:
    interpretation_lens = culture.worldview  # How to understand it
    expression_forms = culture.aesthetics   # How to express it
    value_hierarchy = culture.priorities    # What matters most
    social_rules = culture.norms            # What's acceptable

    # Result = universal force + cultural container
    manifestation = force_dynamics.filtered_through(
        interpretation_lens,
        expression_forms,
        value_hierarchy,
        social_rules
    )

    return manifestation  # Same force, different appearance
```

**Key Insight:** Cultural relativism applies to **expression**, not **mechanism**. The forces work the same way everywhere, but cultures emphasize different aspects and express them differently.
