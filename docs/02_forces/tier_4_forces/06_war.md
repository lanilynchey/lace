# war()

### **Definition**

War is **systemic reordering through conflict** - forced mutation via incompatible pattern collision.

**Synthesis:**
```
war()
├── polarity() [Tier 1]          ← Irreconcilable opposition
├── fear() [Tier 3]              ← Threat perception
├── judgment() [Tier 3]          ← Us vs. them evaluation
├── desire() [Tier 3]            ← Resource competition
└── entropy() [Tier 1]           ← Accelerated chaos
```

**Core Function:**
```python
def war(system_a: System, system_b: System) -> SystemState:
    """
    Conflict-based reordering - forced evolution under pressure.
    
    Args:
        system_a: First incompatible system
        system_b: Second incompatible system
    
    Returns:
        Resolved state (one dominates, both transform, or both collapse)
    
    Properties:
        - Entropy accelerator (rapid disorder injection)
        - Pattern disruptor (destroys rigid structures)
        - Evolutionary catalyst (forces adaptation)
        - Destructive (high cost in lives/resources)
    
    Synthesis:
        polarity() + fear() + judgment() + desire() + entropy()
    
    Descendants:
        - violence() [primitive] - Direct physical conflict
        - competition() [sublimated] - Non-violent rivalry
        - revolution() [systemic] - Internal system war
    """
    tension = detect_incompatibility(system_a.protocols, system_b.protocols)
    
    if tension >= threshold:
        initiate_conflict(system_a, system_b)
        collapse = trigger_reordering(system_a, system_b)
    
    return resolve(collapse)
```

**LACE Position on War Morality:**
```python
# War is NOT morally neutral, but moral evaluation depends on:

def evaluate_war_morality(war_instance):
    """Objective moral assessment of conflict"""

    # 1. Coherence Impact
    coherence_destroyed = measure_pattern_disruption(war_instance)

    # 2. Consent Violation
    consent_level = assess_voluntary_participation(war_instance)

    # 3. Intention
    purpose = extract_intention(war_instance)

    if purpose == "defense" and consent_level == "forced":
        # Defensive war: tragic but not evil
        return "necessary_evil"  # System protection

    elif purpose == "expansion" and coherence_destroyed > threshold:
        # Aggressive war: coherence violation
        return "harmful"  # Violates consent + destroys patterns

    elif purpose == "annihilation":
        # Genocidal war: maximal evil
        return "evil"  # Massive coherence destruction
```

**Key Distinctions:**
- **Defensive war** is like immune response - system protecting itself (tragic but necessary)
- **Aggressive war** is like cancer - one system consuming another (harmful)
- **Genocidal war** is like systemic poison - intentional destruction (evil)

**This preserves LACE's non-relativist stance:** Coherence and consent provide objective standards. War that preserves coherence (defensive) is morally different from war that destroys it (aggressive/genocidal).
