# madness()

### **Definition**

Madness is **pattern overload or coherence collapse** - when recursive loops overwhelm processing capacity.

**Synthesis:**
```
madness()
├── memory() [Tier 2]           ← Unresolved recursion
│   └── time() [Tier 2]         ← Looped states
├── pattern() [Tier 1]          ← Self-similarity collapse
├── coherence() [Tier 1]        ← System breakdown
└── consciousness() [Tier 1]    ← Reflexive awareness amplifies
```

**Core Function:**
```python
def madness(agent: Agent) -> AlteredState:
    """
    Coherence breakdown - pattern recognition overwhelm.
    
    Args:
        agent: The entity experiencing coherence collapse
    
    Returns:
        Agent with fragmented reality processing
    
    Properties:
        - Pattern overload (too much signal, no filter)
        - Reality detachment (internal > external signal)
        - Recursive amplification (loops strengthen)
        - Can be temporary or permanent
    
    Synthesis:
        memory() + pattern() + coherence() + consciousness()
    
    Descendants:
        - psychosis() [severe] - Complete reality detachment
        - neurosis() [mild] - Contained dysfunction
        - genius() [productive] - Coherence edge creativity
    """
    if pattern_complexity > processing_capacity:
        overflow(signal)
        fragment(reality_model)
        amplify(internal_loops)
    
    return altered_state(agent)
```
