# luck()

### **Definition**

Luck is **favorable entropy modulation** - beneficial randomness that appears when field conditions allow.

**Synthesis:**
```
luck()
├── entropy() [Tier 1]          ← Randomness field
├── field_state() [derived]     ← Openness + expectation
├── karma() [Tier 2]            ← Probability constraints
│   └── time() [Tier 2]
├── coherence() [Tier 1]        ← Can agent hold benefit?
└── consciousness() [Tier 1]    ← Meaning assignment
```

**Core Function:**
```python
def luck(agent: Agent) -> Event:
    """
    Favorable anomaly window - guided randomness.
    
    Args:
        agent: The entity experiencing luck
    
    Returns:
        Beneficial event (if field primed)

        - Not random (conditional on field state)
        - Timing-dependent (right place, right time)
        - Coherence-gated (must be able to integrate)
        - Karma-constrained (within probability field)

        entropy() + field_state() + karma() + coherence() + consciousness()

        - serendipity() [meaningful] - Luck + synchronicity

    entropy_pool = access_random_seed()
    
    if agent.field == "primed":  # Open + expectant + present

        return null_event()
```

### **Observer-Relative Randomness**

**LACE Position:** Luck appears random from the individual's perspective but is constrained by deterministic field dynamics.

```python
# From the system's perspective (God's eye view):
# Luck is deterministic - outcome follows from field state + karma + entropy seed
system_view = {
    "randomness": False,  # All variables known → outcome predictable
    "determinism": True,  # Field state determines probability distribution
    "mechanism": "entropy biased by field conditions"
}

# From the observer's perspective (individual human):
# Luck appears random - cannot predict or control
observer_view = {
    "randomness": True,   # Outcome unpredictable from agent's knowledge
    "determinism": False,  # Appears to "just happen"
    "experience": "surprising benefit or coincidence"
}

# Both are true simultaneously:
# - Deterministic at system level (follows field laws)
# - Random at observer level (insufficient information to predict)
```

**Analogy:** Radioactive decay
- **System level:** Quantum mechanics is deterministic (wavefunction evolution)
- **Observer level:** Individual decay event is unpredictable (appears random)
- **Both true:** Determinism doesn't mean predictability from limited perspective
