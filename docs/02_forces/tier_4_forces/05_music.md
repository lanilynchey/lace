# music()

### **Definition**

Music is **structured vibration over time** - temporal patterns that encode and transmit emotion.

**Synthesis:**
```
music()
├── pattern() [Tier 1]      ← Rhythm, harmony, repetition
├── time() [Tier 2]         ← Temporal scaffolding
├── emotion() [derived]     ← Embedded affect
├── coherence() [Tier 1]    ← Aesthetic unity
└── entropy() [Tier 1]      ← Improvisation, syncopation
```

**Core Function:**
```python
def music(source_signal: Signal) -> TemporalPattern:
    """
    Emotion quantized and distributed over time.
    
    Args:
        source_signal: The emotional/conceptual content

        - Non-verbal (bypasses language)
        - Universally accessible (cross-cultural transmission)
    
    Synthesis:
        pattern() + time() + emotion() + coherence() + entropy()
    
    Descendants:
        - song() [specialized] - Music + language
        - ambient() [specialized] - Pure atmosphere
        - rhythm() [specialized] - Temporal structure emphasis
```
