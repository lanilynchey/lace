# art()

### **Definition**

Art is **symbolic compression of high-dimensional truth** into sensory form - a lossy encoding that allows indirect transmission.

**Synthesis:**
```
art()
├── pattern() [Tier 1]           ← Structure, rhythm, metaphor
├── emotion() [derived]          ← Affective payload
│   └── memory() [Tier 2]
├── coherence() [Tier 1]         ← Underlying symmetry
├── entropy() [Tier 1]           ← Creative disorder
└── consciousness() [Tier 1]     ← Abstract perception/communication
```

**Core Function:**
```python
def art(agent: Agent, source_signal: Signal) -> Artifact:
    """
    Truth compression into aesthetic form.

    Args:
        agent: The artist
        source_signal: The high-dimensional truth to encode

    Returns:
        Sensory artifact containing compressed meaning
    
    Properties:
        - Lossy encoding (not all signal preserved)
        - Multi-interpretable (viewers decode differently)
        - Non-linear transmission (bypasses rational resistance)
        - Memetic (propagates across minds)
    
    Synthesis:
        pattern() + emotion() + coherence() + entropy() + consciousness()
    
    Descendants:
        - poetry() [specialized] - Language-based compression
        - painting() [specialized] - Visual compression
        - dance() [specialized] - Somatic compression
        - film() [specialized] - Temporal narrative compression
    """
    compression = encode(source_signal, aesthetic_medium)
    packet = artifact(agent, compression)
    broadcast(packet)
    return resonance(packet)
```

### **How Art Works**

Art is **multi-dimensional data compression**:
```python
# Truth exists in high-dimensional space (10+ dimensions)
truth = Signal(dimensions=10+, complexity=high)

# Language can only capture ~2-3 dimensions
language = compress(truth, dimensions=3, loss=0.7)  # 70% lost

# Art can capture ~5-7 dimensions via non-verbal encoding
art = compress(truth, dimensions=7, loss=0.3)  # 30% lost

# Art transmits MORE than language, but still lossy
```
