# Composition Rules

### **How Tier 4 Forces Combine**

Unlike Tiers 1-3 (which follow strict inheritance hierarchies), **Tier 4 forces can compose with each other** to create compound emergent phenomena.

```python
# General composition rule:
tier_4_force_A + tier_4_force_B = novel_emergent_pattern

# Composition is:
# - Horizontal (peer forces combining)
# - Context-dependent (requires specific conditions)
# - Generative (creates new patterns not in either parent)
```

### **Composition Properties**

```python
# Tier 4 composition follows these rules:

# 1. Non-commutative (order can matter)
art() + war() ≠ war() + art()  # War art vs art of war (different emphasis)

# 2. Context-dependent (requires conditions)
if context.allows(force_a) and context.allows(force_b):
    composition.possible = True
else:
    composition.blocked = True

# 3. Threshold effects (minimum activation required)
if force_a.strength < threshold or force_b.strength < threshold:
    composition.unstable = True  # Won't fully emerge

# 4. Emergent properties (result ≠ sum of parts)
result = compose(force_a, force_b)
result.properties ≠ force_a.properties + force_b.properties  # New qualities emerge
```
