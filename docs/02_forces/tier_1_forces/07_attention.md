## Relationship to consciousness()

These forces are related but distinct:

```python

def reflexive_attention():

    """

def diffuse_awareness():
    """
    Awareness without focus - consciousness in receptive mode.
    Example: Meditation, open awareness, peripheral processing
    """
    return consciousness(focus=None)

def directed_attention():
    """
    Conscious, intentional focus.
```

**Key insight:** You can be conscious without attending to something specific (diffuse awareness). You can attend to something before becoming conscious of it (reflexive capture). They are separable.

```python
attention_model = {
    "bandwidth": "limited",           # Cannot attend to everything

    "recovery": "required",           # Attention depletes, needs restoration
    "quality": "varies",              # Focused vs. scattered
    "voluntary": "partial",           # Some automatic, some directed

```

**Bandwidth limitations:**
- Human attention can track ~4-7 discrete objects
- Switching cost exists (attention residue)
- Divided attention degrades all attended targets
- Deep focus requires protection from interruption

**Consciousness is what perceives. Attention is what selects.**

**You don't just have attention. You ARE attention occurring - selecting reality moment by moment.**
