## Graph Terminology

Network analysis uses specific terms with precise meanings:

### **Node**
A force or law in the system. In graph theory, nodes are the "vertices" - distinct entities connected by edges. LACE has 50 nodes total (26 forces + 24 laws).

### **Edge**
A connection between nodes. Edges can represent:
- **Inheritance** (vertical: parent force → child force)
- **Interaction** (horizontal: force × force → emergent result)
- **Enforcement** (law → force constraint)

Direction matters: `A → B` means A influences/creates/constrains B.

### **Degree**
The number of connections a node has.
- **In-degree:** Incoming connections (dependencies)
- **Out-degree:** Outgoing connections (influences)
- **Total degree:** In-degree + out-degree

Example: consciousness() has ~25+ total degree (highest in graph).

### **Hub Force**
A node with high degree (many connections). Hubs connect multiple domains and act as central integration points. Examples: consciousness(), pattern(), memory().

### **Router Force / Bridge**
A node with high **betweenness centrality** - it sits on many shortest paths between other nodes, connecting otherwise separate clusters. Removing a router fragments the network. Examples: time() (bridges Tier 1→2→3), coherence() (bridges structure/emotion/ethics).

### **Terminal Force**
A node with low out-degree (few descendants). Terminal forces are "endpoints" that don't generate many child forces. Examples: courage(), beauty(), humor().

### **Black Wire Edge / Anomalous Connection**
A connection that violates the expected hierarchy (tier structure). These are non-standard edges that create "sideways" or "backward" influences. Examples: madness()↔art(), music()→time().

### **Path**
A sequence of connected nodes showing how forces cascade: A → B → C → D. Path length is the number of hops.

### **Loop / Cycle**
A path that returns to its starting node: A → B → C → A. Feedback loops are the primary mechanism for self-reinforcing or self-correcting dynamics.

### **Clustering Coefficient**
A measure of how interconnected a node's neighbors are. High clustering = many triangles (if A connects to B and C, B and C also connect). LACE has high clustering due to force interdependencies.

### **Network Density**
The ratio of actual edges to possible edges. 100% density = complete graph (every node connects to every other). LACE has ~23% density (highly interconnected but not complete).
