### **Pathological Cascades (Destructive Patterns)**

These cascades show common destructive force interactions - the "dark side" of the graph.

#### **Path 5: Addiction Formation**
```
[DOPAMINE SPIKE]
    ↓
desire() → intense_craving
    ↓
action → substance/behavior
    ↓
pleasure → temporary_fulfillment
    ↓
memory() → encodes(pleasure + trigger)
    ↓
entropy() → pleasure_fades
    ↓
pain(absence) → withdrawal
    ↓
desire() → amplified_craving [stronger than before]
    ↓
[ADDICTION LOOP]
```

**What This Pattern Shows:**
- Desire + memory + entropy create self-amplifying loops
- Each cycle strengthens the neural pathway (memory consolidation)
- Withdrawal pain exceeds original desire intensity
- Classic positive feedback loop (addiction medicine)

**Breaking This Pattern:**
- Interrupt at desire: observe without acting (mindfulness)
- Interrupt at memory: heal associations (EMDR, reconsolidation therapy)
- Interrupt at action: substitute behavior (harm reduction)

#### **Path 6: Shame Spiral**
```
[PERCEIVED FAILURE]
    ↓
judgment(self) → "I am bad"
    ↓
pain(identity_wound) → shame_feeling
    ↓
judgment(pain) → "I shouldn't feel this"
    ↓
pain(pain) → meta-shame [shame about shame]
    ↓
coherence() → identity_collapse
    ↓
fear(visibility) → social_withdrawal
    ↓
isolation → more_judgment
    ↓
[SHAME SPIRAL / DEPRESSION]
```

**What This Pattern Shows:**
- judgment() applied to self creates recursive pain amplification
- Meta-emotions (shame about shame, fear of fear) create secondary loops
- Coherence breakdown from internal contradiction
- Leads to social withdrawal which amplifies isolation

**Breaking This Pattern:**
- Interrupt at judgment: self-compassion practice (forgiveness(self))
- Interrupt at pain: feel without judging (witness mode)
- Interrupt at coherence: identity_work (self as process not fixed entity)

#### **Path 7: Paranoia Formation**
```
[HYPERVIGILANCE STATE]
    ↓
fear() → threat_scanning
    ↓
pattern() → sees_connections_everywhere
    ↓
judgment() → assigns_malicious_intent
    ↓
memory() → stores_false_positives
    ↓
truth() → distortion [confirmation bias]
    ↓
fear() → amplified_hypervigilance
    ↓
pattern() → more_false_patterns
    ↓
[PARANOIA / CONSPIRACY THINKING]
```

**What This Pattern Shows:**
- fear() + pattern() = apophenia (seeing patterns that aren't there)
- judgment() adds intentionality to random events
- memory() consolidates false positives more than true negatives
- truth() gets warped by confirmation bias
- Classic paranoid thinking loop

**Breaking This Pattern:**
- Interrupt at fear: safety cultivation (environment/relationships)
- Interrupt at pattern: reality testing (check predictions)
- Interrupt at judgment: assume neutral intent
- See TIER_3_FORCES.md for judgment() healthy vs. unhealthy expressions

---

**Note:** These pathological patterns are NOT moral failures - they're natural system dynamics under specific conditions. Understanding the graph mechanics enables compassionate intervention rather than judgment.
