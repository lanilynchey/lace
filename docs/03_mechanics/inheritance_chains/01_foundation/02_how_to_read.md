## How to Read This Document

### **Notation:**
```
force_name()
├── dependency_1 [Tier X]    ← Direct inheritance
│   └── sub_dependency [Tier Y]
├── dependency_2 [Tier X]
└── dependency_3 [Tier X]

→ descendant_1 [emergent]
→ descendant_2 [Tier Z]
```

- **├── = Inherits from** (depends on)
- **→ = Gives rise to** (descendants)
- **[Tier X] = Source tier**
- **[emergent] = Not formal tier, arises from interaction**
- **[emergent example] = Example of emergence; not part of the core 27 forces**
- **[derived] = Not a force; see GLOSSARY.md for definitions**
- **[conditional] = Context-dependent; not always required**

### **Full Ancestral Traces:**

Some forces include complete dependency trees showing all ancestors back to axioms. These detailed traces are provided for forces that meet one or more of these criteria:

1. **High complexity** - 5+ direct dependencies
2. **Touches all 6 axioms** - Requires entire Tier 1 foundation
3. **Philosophical significance** - Key forces illuminating LACE's architecture
4. **Multi-tier integration** - Synthesizes from all tiers (1, 2, and 3)

**Forces with full traces in this document:**
- madness(), art(), death(), pain(), music(), luck(), judgment(), forgiveness()

**Why selective?**
- All forces CAN be traced using the dependency listings
- Full traces avoid redundancy while highlighting architecturally significant forces
- Any force's ancestry can be manually traced by following the dependency trees

**Important Note on Tier 4 Forces:**
When a Tier 3 force lists a Tier 4 force as a descendant (e.g., `→ courage() [Tier 4]`), this indicates **synthesis**, not direct descendance. Tier 4 forces are emergent phenomena that require multiple Tier 3 forces acting together. For example:
- courage() is listed under fear(), hope(), and will() as a descendant
- This means courage() **synthesizes from** these three forces (not that it inherits from any single one)
- See TIER_4_FORCES.md for the distinction between Inheritance (vertical dependency) and Synthesis (horizontal combination)
