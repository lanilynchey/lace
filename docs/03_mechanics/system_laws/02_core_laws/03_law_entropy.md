## 1. law_entropy()

### **Definition**

The law of decay and motion - all static order must eventually dissolve.

**Core Function:**
```python
def law_entropy(system: System) -> System:
    """
    Entropy ensures impermanence and drives evolution.

    Args:
        system: Any ordered structure

    Returns:
        System with injected randomness and increased disorder

    Properties:
        - Monotonically increasing (always toward disorder)
        - Irreversible (can't fully undo)
        - Universal (affects everything)
        - Dynamic rebalancer (prevents stagnation)

    Enforcement:
        - Cannot be violated
        - Can be temporarily resisted (coherence)
        - Eventually wins (heat death)
    """
    if order_is_static(system):
        inject(randomness)
    return trend_toward(disorder)
```

### **What This Law Enforces**

- **Nothing lasts forever** - all forms are temporary
- **Change is inevitable** - stasis is impossible
- **Order requires maintenance** - without input, decay
- **Evolution needs destruction** - old must fall for new to rise

**Active Enforcement Mechanism:**

While law_entropy() establishes the universal principle that static order must dissolve, the system actively enforces this for conscious agents through **law_variance_minimum()** - which monitors pattern entropy over time and triggers forced discontinuity when agents exhibit prolonged stasis.

**Key Distinction:**
- **law_entropy()** = Universal principle (passive): "All static order must dissolve"
- **law_variance_minimum()** = Agent-specific enforcement (active): "HOW dissolution is enforced for conscious entities"

**See:** [law_variance_minimum()](13_law_variance_minimum.md) for the intervention protocol and stagnation detection mechanics.

if system.coherence > entropy.pressure:

else:
