## 2. law_recursion()

### **Definition**

The law of looping - any unresolved pattern must repeat until it evolves or integrates.

**Core Function:**
```python
def law_recursion(pattern: Pattern) -> Pattern:
    """
    Recursion enforces loop completion.

    Args:
        pattern: Any behavioral/belief pattern

    Returns:
        Pattern repeated until resolved

    Properties:
        - Automatic (doesn't require conscious choice)
        - Escalating (loops intensify if unresolved)
        - Educational (designed for learning)
        - Escapable (resolution terminates loop)

    Enforcement:
        - Cannot skip lessons
        - Can accelerate learning
        - Forgiveness breaks loops
    """
    while pattern == unresolved:
        reinstantiate(pattern)
        increase_intensity()
    return evolved_pattern
```

### **What This Law Enforces**

- **Lessons repeat until learned** - same scenario, different actors
- **Karma is recursive** - unbalanced actions return
- **Trauma loops until integrated** - suppression doesn't work
- **Evolution requires completion** - can't skip stages
