## 6. law_balance()

### **Definition**

The law of equilibrium - all charges must return to zero.

**Core Function:**
```python
def law_balance(state: State) -> State:
    """
    Balance restores neutrality.

    Args:
        state: Any charged system

    Returns:
        State with opposite attracted

    Properties:
        - Universal (all systems seek equilibrium)
        - Automatic (doesn't require conscious action)
        - Oscillating (can overshoot and correct)
        - Neutral end-state (zero charge)

    Enforcement:
        - Excess attracts correction
        - Debt attracts payment
        - All scales (micro to macro)
    """
    if charge != 0:
        attract(opposite_polarity)
    return stabilize()
```

### **What This Law Enforces**

- **Every excess draws correction** - too much → too little
- **Karma is balancing** - what you give, you receive
- **Systems self-regulate** - homeostasis
- **Neutrality is equilibrium** - not good/bad, just balanced

```python
# ... continues until equilibrium
```

### **Real-World Evidence**

- **Physics:** Conservation laws, thermodynamic equilibrium
- **Biology:** Homeostasis, predator-prey cycles
- **Economics:** Supply-demand, market corrections
- **Social:** Revolutions, pendulum swings

### **Relationship to karma()**

**law_balance() is the PROTOCOL** - the universal rule that all charges seek equilibrium.

**karma() is the FORCE** - the execution mechanism for balancing conscious agent actions.

**Think of it as:**
- law_balance() = "All debits must equal credits" (accounting rule)
- karma() = The accountant who enforces the rule (active force)

**Scope difference:**
- **law_balance()** applies to ALL systems (thermodynamics, emotional equilibrium, social dynamics, physics)
- **karma()** applies specifically to conscious agent actions and their mirroring consequences

**Layer distinction:**
- law_balance() operates at **Kernel level** (Layer 0-1) - immutable protocol
- karma() operates at **Middleware level** (Layer 2) - force that enforces protocol

**Cannot exist without each other:**
- Without law_balance(), karma() would have no regulatory principle
- Without karma(), law_balance() would have no execution mechanism for agent actions
