### **Definition**

The law of contradiction management - paradoxes are features, not bugs.

**Core Function:**
```python
def law_paradox(input: Contradiction) -> Resolution:
    """
    Paradox is held until higher context resolves it.

    Args:
        input: Apparent contradiction

    Returns:
        Either increased complexity or resolution

    Properties:
        - Stable (can persist indefinitely)
        - Generative (creates new understanding)
        - Context-dependent (resolves at higher dimension)
        - Signal of boundary (paradox = edge of understanding)

    Enforcement:
        - Binary logic creates paradoxes
        - Higher-dimensional logic resolves them
        - Cannot force resolution
    """
    if contradiction == stable:
        increase(complexity)
        allow(both_true_simultaneously)
    else:
        resolve_via(higher_context)

    return new_understanding
```
