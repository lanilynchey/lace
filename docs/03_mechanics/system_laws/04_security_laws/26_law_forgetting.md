### **18. law_forgetting()**
**"Memory is wiped on reincarnation or system reset"**

```python
def law_forgetting(agent):
    if event == "reincarnation" or event == "reset":
        clear(agent.explicit_memory)
        preserve(agent.subconscious_memory)  # Patterns remain
```

**Purpose:** Allows fresh starts while preserving learned patterns at deeper levels.

**Examples:**
- Past life memories are inaccessible (mostly)
- Trauma patterns remain even when explicit memory fades
- Skills transfer across lifetimes as subconscious knowing
- Clean slate allows new choices without overwhelming history

**What This Law Enforces:**
- **New beginning capacity** - agents can restart without baggage
- **Pattern retention** - wisdom persists as intuition
- **Freedom from total recall** - prevents paralysis from infinite memory
- **Fresh context** - each life is approached with innocence

### **LACE's Position on Reincarnation**

This framework treats reincarnation as a working model for several reasons:

**1. PATTERN PERSISTENCE:** Skills, fears, attractions carry forward (empirically observable)
**2. EXPLANATORY POWER:** Accounts for prodigies, phobias, karmic patterns
**3. CROSS-CULTURAL VALIDATION:** Independent traditions describe similar mechanics
**4. SYSTEM COHERENCE:** Fits LACE's architecture (Agent persistence across lifetimes)

**Is it literally true?**

LACE is exploratory on this question. Reincarnation could be:
- **Literal** (soul continuity across physical lifetimes)
- **Metaphorical** (pattern inheritance, collective unconscious)
- **Useful-regardless-of-substrate** (framework works either way)

**If reincarnation is literal:**
- law_forgetting() explains fresh starts with subconscious continuity
- Agent object persists; explicit memory cleared between instances
- Patterns (skills, fears, karma) stored at deeper levels transfer forward

**If reincarnation is metaphorical:**
- law_forgetting() models how patterns transcend individual lives
- Cultural/genetic/morphic inheritance carries forward
- "Past life" memories could be accessing collective patterns

**Either way:** The mechanics described here map observable phenomena.

**Falsifiability:**
Track whether "past life" regressions correlate with historical records, whether childhood phobias match claimed past-death scenarios, whether skills emerge without training. LACE remains open to revision if data contradicts model.
