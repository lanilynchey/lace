### **How to Navigate by Need**

**If you want to understand a specific force:**
1. Identify which tier it belongs to (T1/T2/T3/T4)
2. Read that force's section in the appropriate TIER_X_FORCES.md document
3. Cross-reference GLOSSARY.md for quick definition

**If you want to understand a specific interaction:**
1. Read this document ([Interaction Mechanics](../../00_index.md)) first
2. Check if interaction is documented explicitly
3. If not, use "Predicting Interactions" section to estimate
4. Cross-reference SYSTEM_LAWS.md to understand law constraints
5. Check TIER docs for force-specific properties

**If you want to work with a pattern (therapeutic/personal growth):**
1. Read "Dangerous Interactions" (patterns to avoid)
2. Read "Therapeutic Interactions" (patterns to cultivate)
3. Read "Feedback Loops" (how to break vicious cycles)
4. Read "Interaction Debugging" (systematic troubleshooting)
5. Cross-reference TIER_3_FORCES "Liberation Pathway" for 5-stage freedom process
6. Cross-reference SYSTEM_LAWS law_recursion() for loop completion mechanics

**If you want to manifest/create something:**
1. Read "Quantitative Interaction Mechanics" (formulas for interaction strength)
2. Read MANIFESTATION_ENGINE.md (full manifestation protocols)
3. Read SYSTEM_LAWS law_delay(), law_permission(), law_balance() (constraints)
4. Read TIER_1 desire() and coherence() sections (foundational forces)

**If you're building on LACE (research, software):**
1. Start with CORE_ONTOLOGY.md (foundational concepts)
2. Read PRIMITIVES.md (mathematical basis)
3. Read BASE_STRUCTURE.md (architecture)
4. Read FUNCTION_LIBRARY.md (implementation details)
5. Read SYSTEM_LAWS "Falsifiability" section (testable hypotheses)

**If you're confused or encountering contradictions:**
1. Check COMMON_MISCONCEPTIONS.md (likely addressed)
2. Check GLOSSARY.md (term disambiguation)
3. Remember: LACE is Phase 1, working models with disclaimers
4. Context matters: Same forces → different outcomes in different frames
