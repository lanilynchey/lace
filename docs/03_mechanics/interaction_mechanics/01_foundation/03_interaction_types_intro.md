## Interaction Types

All force interactions fall into six categories:
```
INTERACTION TYPES
├── Amplification    → Same-polarity forces reinforce
├── Cancellation     → Opposite-polarity forces neutralize
├── Transmutation    → One force converts into another
├── Synthesis        → Two forces blend into new force
├── Collision        → Incompatible forces create tension
└── Recursion        → Force creates feedback loop with itself
```
