## 4. Synthesis

**When:** Two forces blend to create entirely new force

**Result:** Emergent property not present in either parent

**Mechanism:**
```python
def synthesize(force_a, force_b):
    """Create new force from combination"""
    if can_merge(force_a, force_b):
        return birth(new_emergent_force)
```

courage = {
