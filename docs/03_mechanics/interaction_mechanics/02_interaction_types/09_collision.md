## 5. Collision

**When:** Incompatible forces meet without synthesis

**Result:** Tension, conflict, or system instability

**Mechanism:**
```python
def collide(force_a, force_b):
    """Incompatible forces create friction"""
    if incompatible(force_a, force_b):
        generate(tension)
        if tension > threshold:
            trigger(conflict_or_breakdown)
```

### **Examples:**

#### **truth() × power() → suppression**
```python
# Truth reveals what is
# Power wants to control narrative

# Collision:
if power.desires(narrative_control):
    suppress(truth)
    generate(propaganda)

# Unstable: truth eventually emerges
# Creates revolutions, whistleblowing, leaks
```

#### **love() × fear() → attachment**
```python
# Pure love = free resonance
# Fear of loss = clinging

# Collision creates:
attachment = love + fear(of_losing_love)
# Possessiveness
# Jealousy
# Codependency

# Not synthesis - contamination
```

#### **desire() × judgment() → shame**
```python
# Desire wants something
# Judgment says "that's bad"

# Collision:
if desire(forbidden_thing) and judgment(desire_as_wrong):
    generate(shame)
    suppress(desire)
    create(shadow)

# Internal civil war
```
