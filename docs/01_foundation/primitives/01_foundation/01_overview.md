# Overview

Before forces, before laws, before even the primordial axioms—there exist **primitives**. These are the irreducible units from which all else is composed.

Think of them as:
- **Subatomic particles** in physics
- **Primitive data types** in programming (int, float, bool)
- **Axioms** in mathematics (undefined terms that define everything else)
- **Root phonemes** in language (sounds that build words)

**Everything in LACE inherits from these primitives.**

> **Note on Completeness:** These five primitives represent our current understanding of reality's substrate layer. There may be additional primitives yet to be discovered or revealed. This is a starting set based on revelatory, inferential, experiential, and conceptual evidence. See [Advanced Concepts](../../../04_advanced/advanced_concepts/00_index.md) for epistemological discussion.

## Primitive Types of Existence

These are not particles. They are **informational units** - the substrate code of reality.
