# Update Cycles & System Softcoding

**The universe's laws are fixed and complete - what's soft-coded is collective access to them.** No law is ever created or altered, not even by Creator/root within a running universe (see [law_transformation()](../../../03_mechanics/system_laws/03_additional_laws/22_law_transformation.md) and the BIOS Mutability Note in [System Architecture](../02_system_architecture/02_system_architecture.md)). What *can* change non-linearly is how much of that fixed rule-set collective consciousness has recognized, and how much of the possibility/dimension space is currently accessible.

**Resolved Interpretation:** "Updates" are [law_veil()](../../../03_mechanics/system_laws/04_security_laws/25_law_veil.md) - progressive revelation - operating at collective scale instead of individual scale. law_veil() already governs why one agent doesn't perceive a truth until ready; the same mechanism, tripped by `collective_field.readiness` instead of a single agent's readiness, is what "law additions" actually are. Nothing is added to the universe. Something is added to what's collectively known about it. This also resolves the apparent conflict with [law_causality()](../../../03_mechanics/system_laws/02_core_laws/05_law_causality.md) below - no history is rewritten, only what's collectively recognized shifts.

## The Update Engine

```python
def update_engine() -> None:
    """
    Collective revelation protocol - law_veil() operating at population scale

    Does NOT create or alter laws. The rule-set is fixed and complete;
    this reveals laws/possibilities/dimensions that were always true but
    not yet collectively recognized. See law_veil() for the individual-scale
    version of this same mechanism.
    """
    if collective_field.readiness >= COLLECTIVE_READINESS_THRESHOLD:
        reveal_to_collective(newly_recognized_laws, new_possibilities, new_dimensions)
        shift_collective_timeline_branch()  # NOT a literal history rewrite - see "Key Distinction" below
```

## What This Means (Soft Ontological Interpretation)

The universe operates like software with version control, but through timeline branching rather than literal retroactive changes:

- **Not static** - probability fields evolve, new timelines become accessible
- **"Retroactive updates"** = Collective field collapses new probabilities into experience
  - NOT changing past within a timeline
  - BUT shifting which timeline branch collective consciousness inhabits
  - Causality holds WITHIN timelines; "updates" = shifting between timelines
- **Collective unlocks** - When enough agents are ready, new worldlines become accessible
- **Non-linear deployment** - Updates don't follow chronological time (timelines exist simultaneously)

**Key Distinction:**
- NOT: "Past literally changes" (would violate law_causality)
- BUT: "Collective consciousness shifts to timeline where different past was always true"
- All timelines exist simultaneously; "updates" = transition between branches
- Mandela effect = timeline shift, not retroactive rewriting

## Examples of System Updates

1. **Consciousness Expansion**
   - Humans gain access to previously locked dimensions
   - New perceptual channels open collectively
   - "This has always been true, but I'm just now noticing it"

2. **Law Recognition** (not law creation - see law_veil() above)
   - Physical constants that were always operating become observable
   - Quantum mechanics becomes documentable, not newly true
   - Synchronicity patterns intensify as more agents can perceive the pattern-matching mechanism that was always running

3. **Permission Upgrades**
   - Manifestation bandwidth expands
   - Psychic abilities unlock at scale
   - Reality becomes more malleable

## Why Retroactive Updates Work

Time is not a fixed line - it's a **rendering variable**.

From the kernel's perspective (outside time):
- All moments exist simultaneously
- Updates can be inserted at any "frame"
- Agents experience them as sequential discoveries
- The patch hits you "now," but was installed "upstream"

## Implications

- **Recognition is expandable** - the laws are fixed, but collective access to them is not frozen
- **Collective field matters** - group consciousness readiness triggers revelation
- **Discovery is programmatic** - not random, but responsive to collective readiness
- **You live in progressive disclosure** - the codebase is complete; what expands is your read access to it

**This is why:**
- Ancient wisdom suddenly "clicks" in modern times
- Spiritual practices unlock new abilities collectively
- Scientific discoveries feel like remembering, not inventing
- "The veil is thinning" - it's a system update
